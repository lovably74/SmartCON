## 1. 새로운 요구사항 상세 분석

### 1.1 통합 로그인 시스템 (0% 완성)

#### 🎯 구현해야 할 기능
- **모바일 로그인 페이지**: 개인사용자/관리자 탭 구분
- **개인사용자 로그인**:
  - 소셜 로그인 (카카오톡, 네이버)
  - 최초 로그인 시 전화번호 인증
  - CI값 기반 사용자 통합 관리
  - 기존 CI값 있을 경우 소셜정보 추가
- **관리자 로그인**:
  - 사업자번호 + 비밀번호 인증
  - 2차 이메일 인증 수행
- **권한 선택 시스템**:
  - 2개 이상 권한 보유 시 선택 기능
  - 현장관리자/노무팀장의 현장 선택
  - 현장 목록 정렬 및 필터링

### 1.2 5단계 역할 기반 시스템 (0% 완성)

#### 🎯 역할별 구현 범위

**본사관리자**:
- 대시보드 (진행중 현장, 노무자, 미서명 계약 카운트)
- 프로젝트 현황 (신규 등록, 목록, 상세현황)
- 출역현황 (전체 현장 출역현황 조회)
- 근로계약현황 (프로젝트별 계약서 목록)
- 노무자현황 (전체 노무자 목록)
- 관리자관리 (본사관리자 목록 및 초대)
- 구독관리 (회사정보, 계약담당자, 청구서)

**현장관리자**:
- 대시보드 (금일 출역자, 미서명 계약 카운트)
- 프로젝트 개요 (현장 정보 표시)
- 출역현황 (현장별 출역현황 조회 및 수정)
- 근로계약현황 (수정요청 계약 확인 및 재발송)
- 노무자현황 (기본단가 설정 및 수정)
- 신규출역자 확인 (승인 관리)

**노무팀장**:
- 대시보드 (팀원수, 출역 수, 팀원현황)
- 프로젝트 개요 (현장 정보 표시)
- 출역조회 (팀별 출역현황 조회)
- 근로계약현황 (미서명자 서명 요청)
- 노무자현황 (팀원 목록 관리)

**일반노무자**:
- 대시보드 (개인 출역 현황)
- 프로젝트 개요 (참여 현장 정보)
- 출역조회 (개인 출역현황 조회)
- 근로계약현황 (계약내용 변경 요청)
- 안면인식 등록 (현장별 안면정보 수정)
