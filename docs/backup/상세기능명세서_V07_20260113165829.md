# SmartCON Lite 역할 기반 시스템 상세기능명세서

**문서 버전:** 7.0  
**작성일:** 2026년 1월 13일  
**최종 수정일:** 2026년 1월 13일  
**작성자:** Kiro AI Assistant  
**변경 기반:** 현장관리자 출역현황 관리 및 안면인식기 연동 개선 요구사항 반영

---

## 1. 문서 개요

본 문서는 SmartCON Lite 역할 기반 시스템의 상세 기능명세를 정의합니다. 
변경된 요구사항에 따라 5단계 사용자 역할(본사관리자, 현장관리자, 노무팀장, 일반노무자, 슈퍼관리자)별 기능과 
모바일 우선 설계 기반의 시스템 요구사항을 포함합니다.

### 1.1 문서 목적
- 변경된 요구사항에 따른 상세 구현 가이드 제공
- 역할별 사용자 스토리 및 수용 기준 정의
- 통합 인증 시스템 및 CI값 기반 사용자 관리 명세
- 모바일 우선 설계 및 크로스 플랫폼 지원 방안

### 1.2 적용 범위
- PC웹 애플리케이션 (React + TypeScript)
- 모바일웹 애플리케이션 (반응형 웹)
- 모바일 앱 (Capacitor 기반 하이브리드 - Android/iOS)
- 백엔드 API (Spring Boot + MariaDB)
- 외부 연동 시스템 (FaceNet, 소셜 로그인, SMS)

### 1.3 핵심 변경사항 (V7.0)
- **통합 로그인 시스템**: 개인사용자(소셜) / 관리자(사업자번호) 구분
- **CI값 기반 사용자 관리**: 전화번호 인증을 통한 고유 키값 및 계정 연동
- **역할별 대시보드**: 5단계 역할별 맞춤 대시보드 및 기능
- **현장 선택 시스템**: 다중 현장 소속 사용자를 위한 현장 선택
- **모바일 우선 설계**: PC웹, 모바일웹, 모바일앱 통합 지원
- **출역현황 관리 개선**: 출역 승인/반려 제거, 출근/퇴근시간 수정 기능 추가
- **안면인식기 자동 연동**: 신규 출역자 승인시 안면인식기 정보 자동 전달
- **실시간 출역 데이터 처리**: 안면인식기 API 연동을 통한 자동 출역 기록 처리

## 2. 시스템 아키텍처 및 기술 스택

### 2.1 멀티테넌트 아키텍처
- **격리 방식**: Shared Database, Shared Schema with tenant_id
- **테넌트 식별**: JWT 토큰 내 tenant_id 포함
- **데이터 격리**: 모든 비즈니스 테이블에 tenant_id 컬럼 강제
- **파일 격리**: S3 경로에 tenant_id 포함 (s3://bucket/{tenant_id}/...)

### 2.2 기술 스택 상세
#### Frontend
- **Framework**: React 18.2+ with TypeScript 5.0+
- **Build Tool**: Vite 5.0+ (HMR, Tree-shaking)
- **UI Library**: Shadcn/UI + Tailwind CSS 3.4+
- **State Management**: 
  - Zustand 4.4+ (클라이언트 상태)
  - TanStack Query 5.0+ (서버 상태, 캐싱)
- **Routing**: Wouter 3.0+ (경량 라우터)
- **Mobile**: Capacitor 6.0+ (카메라, GPS, 푸시알림)

#### Backend
- **Language**: Java 17 LTS
- **Framework**: Spring Boot 3.3.x
- **Database**: MariaDB 10.11 with JPA/Hibernate 6.x
- **Security**: Spring Security 6.x + JWT + OAuth2 (Kakao, Naver)
- **Build**: Maven 3.8+

#### Infrastructure
- **Container**: Docker + Docker Compose
- **Storage**: AWS S3 (파일, 이미지)
- **Cache**: Redis 7.x (세션, 임시데이터)
- **CI/CD**: GitHub Actions (권장)

## 4. 인증 및 온보딩 프로세스

### 4.1 통합 로그인 시스템
#### 4.1.1 모바일 로그인 인터페이스
- **사용자 구분 탭**: "개인사용자", "관리자" 선택
- **반응형 디자인**: 모바일 우선, PC웹 대응
- **접근성**: WCAG 2.1 AA 준수

#### 4.1.2 개인사용자 로그인 (소셜 로그인)
**지원 플랫폼**: Kakao, Naver OAuth2

**최초 로그인 플로우**:
1. 소셜 플랫폼 선택 (Kakao/Naver)
2. OAuth2 인증 페이지 리다이렉트
3. 인증 성공 시 전화번호 입력 요구
4. SMS 인증번호 발송 및 확인
5. CI값 생성 및 신규 계정 생성
6. 추가 정보 입력 (이름, 기본 정보)

**기존 사용자 로그인 플로우**:
1. 소셜 플랫폼 선택
2. OAuth2 인증
3. CI값 확인 후 기존 계정에 소셜 정보 추가
4. 역할/현장 선택 후 대시보드 이동

#### 4.1.3 관리자 로그인 (사업자 로그인)
**인증 방식**: 사업자번호 + 비밀번호 + 2차 인증

**로그인 플로우**:
1. 사업자번호 입력 (10자리, 하이픈 자동 삽입)
2. 비밀번호 입력 (8자 이상, 영문+숫자+특수문자)
3. 1차 인증 성공 시 2차 인증 이메일 발송
4. 이메일 인증 코드 입력
5. 인증 완료 후 본사관리자 대시보드 이동

**보안 기능**:
- 5회 실패 시 계정 30분 잠금
- 모든 인증 시도 로그 기록
- HTTPS 강제 적용

### 4.2 역할 및 현장 선택
#### 4.2.1 다중 역할 처리
- **조건**: 사용자가 2개 이상 역할 보유시
- **선택 인터페이스**: 역할별 카드 형태 선택
- **역할 정보**: 각 역할의 권한 및 접근 가능 기능 표시

#### 4.2.2 현장 선택 (현장관리자/노무팀장)
- **조건**: 여러 현장에 소속된 사용자
- **정렬 순서**:
  1. 최근 로그인한 현장
  2. 최근 투입된 현장  
  3. 준공예정일이 많이 남은 현장
- **필터링**: "전체현장", "진행중현장", "완료현장"
- **검색**: 현장명으로 검색 기능

### 4.3 내정보 관리
#### 4.3.1 개인정보 관리
**관리 항목**:
- 이름, 휴대전화번호, 이메일 주소
- 급여 계좌정보 (은행명, 계좌번호, 예금주)
- 사진 (프로필 이미지)
- 주민번호 (마스킹 표시, 수정 불가)
- 비상연락처, 자택주소

**보안 처리**:
- 주민번호, 계좌번호 AES-256 암호화
- 화면 표시시 마스킹 처리
- 수정 이력 로그 기록

#### 4.3.2 소셜계정 관리
- **연결된 계정**: 현재 연결된 소셜계정 목록 표시
- **계정 추가**: 추가 소셜계정 연동 기능
- **계정 해제**: 소셜계정 연결 해제 (최소 1개 유지)

## 5. 본사관리자 (ROLE_HQ) 기능 명세

### 5.1 대시보드 (HQ-DASH)
#### 5.1.1 KPI 지표
- **진행중 현장 카운트**: 현재 활성 상태 현장 수
- **등록(활성) 노무자 카운트**: 전체 활성 노무자 수
- **전체 현장 미서명 계약 카운트**: 서명 대기 중인 계약서 수

#### 5.1.2 차트 및 통계
- **월별 출역 현황**: 최근 12개월 출역 인원 Bar Chart
- **공종별 인원 분포**: 현재 공종별 노무자 분포 Pie Chart

### 5.2 프로젝트 현황 (HQ-PROJ)
#### 5.2.1 신규 프로젝트 등록
**필수 입력 정보**:
- 현장명, 공사기간 (시작일, 종료일)
- 현장소장 정보
- 안면인식기 시리얼 번호

**현장관리자 설정**:
- 기존 현장관리자 선택 (다중 선택 가능)
- 신규 현장관리자 초대 (이름, 휴대전화, 이메일)

#### 5.2.2 프로젝트 목록 관리
**표시 정보**:
- 현장명, 공사기간, 현장소장
- 상태 (진행중/일시중지/완료)
- 출역인원, 등록일
- 안면인식기 등록 수

**기능**:
- 현장명 검색
- 상태별 필터링 ("전체현장", "진행중현장", "완료현장")
- 프로젝트 상세 정보 조회 및 수정

### 5.3 출역현황 (HQ-ATT)
#### 5.3.1 전체 현장 출역현황
**표시 정보**:
- 프로젝트명, 출역노무자명
- 출근시각, 퇴근시각, 출역공수
- 단가, 변경사항 및 사유

**기능**:
- 실시간 출역 현황 조회
- 기간별 필터링
- 현장별, 노무자별 검색

### 5.4 근로계약현황 (HQ-CONT)
#### 5.4.1 계약 목록 관리
**표시 정보**:
- 프로젝트명, 출역일, 노무자명
- 노무자 연락처, 근로계약 서명 여부
- 근로계약서 보기 링크

**기능**:
- 프로젝트별 필터링
- 월별, 일별 조회
- 미서명 계약 일괄 알림

### 5.5 노무자현황 (HQ-WORK)
#### 5.5.1 노무자 목록
**표시 정보**:
- 노무자명, 연락처
- 근무현장 수, 총 출역일
- 근로계약서 카운트
- 최초 출역일, 마지막 출역일

### 5.6 관리자관리 (HQ-ADMIN)
#### 5.6.1 본사관리자 목록
**표시 정보**:
- 이름, 전화번호, 이메일, 직책
- 상태 (입사/퇴사/휴직)
- 입사일, 퇴사일

#### 5.6.2 관리자 초대
**초대 정보**:
- 이름, 휴대전화, 이메일
- SMS 초대 링크 발송
- 초대 상태 추적

### 5.7 구독관리 (HQ-SUB)
#### 5.7.1 회사정보 관리
- 회사 기본 정보 수정
- 사업자등록증 관리
- 회사 로고 업로드

#### 5.7.2 계약담당자 관리
- 계약 담당자 정보 등록/수정
- 청구서 수신 이메일 설정

#### 5.7.3 청구서 및 계산서 조회
- 월별 청구서 조회
- 결제 내역 확인
- 세금계산서 다운로드

#### 5.7.4 결재 이력 조회
- 결제 성공/실패 이력
- 결제 수단 변경 이력
- 구독 변경 이력

## 6. 현장관리자 (ROLE_SITE) 기능 명세

### 6.1 대시보드 (SITE-DASH)
#### 6.1.1 금일 현황
- **금일 신규 출역자 카운트**: 오늘 처음 출역한 노무자 수
- **금일 총 출역자 카운트**: 오늘 총 출역한 노무자 수
- **미서명 계약 카운트**: 현장 내 미서명 계약서 수

#### 6.1.2 통계 차트
- **일별 출역 현황**: 최근 1개월 일별 출역 인원 Bar Chart
- **공종별 인원 분포**: 최근 1개월 공종별 인원 분포 Pie Chart

### 6.2 프로젝트 개요 (SITE-PROJ)
#### 6.2.1 현장 정보 조회
**표시 정보**:
- 현장명, 공사기간, 현장소장
- 상태, 출역인원, 등록일
- 안면인식기 등록 수

### 6.3 출역현황 (SITE-ATT)
#### 6.3.1 현장 출역현황
**표시 정보**:
- 출역노무자명, 소속 팀
- 출근시각, 퇴근시각, 출역공수
- 단가, 변경사항 및 사유

**기능**:
- 기간별, 이름별, 공종별, 소속 팀별 검색
- **출근시간 및 퇴근시간 수정 기능** (현장관리자 권한)
- 출역 데이터 수정 (단가, 공수, 사유)
- **안면인식기 API 연동을 통한 실시간 출역 데이터 수신**
- **출역 승인/반려 기능 제거** (자동 처리)

### 6.4 근로계약현황 (SITE-CONT)
#### 6.4.1 계약 관리
**표시 정보**:
- 출역일, 노무자명, 노무자 연락처
- 근로계약 서명 여부, 근로계약서 보기

**기능**:
- 월별, 일별 조회
- 수정요청 계약 확인 및 재발송
- 공종, 단가 변경 (출역현황에서 수정하여 반영)

### 6.5 노무자현황 (SITE-WORK)
#### 6.5.1 현장 노무자 관리
**표시 정보**:
- 노무자명, 연락처, 공종
- 기본단가, 총 출역일
- 근로계약서 카운트, 최초/마지막 출역일
