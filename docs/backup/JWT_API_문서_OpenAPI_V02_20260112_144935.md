# JWT 토큰 시스템 API 문서 (OpenAPI 3.0)

## 개요

SmartCON Lite JWT 토큰 시스템의 REST API 명세서입니다. 이 문서는 OpenAPI 3.0 표준을 따르며, Swagger UI에서 사용할 수 있습니다.

## OpenAPI 명세서

```yaml
openapi: 3.0.3
info:
  title: SmartCON Lite JWT Authentication API
  description: |
    SmartCON Lite의 JWT 토큰 기반 인증 시스템 API입니다.
    
    ## 주요 기능
    - JWT 토큰 기반 인증
    - 멀티테넌트 지원
    - 역할 기반 접근 제어
    - 토큰 블랙리스트 관리
    - 개발용 토큰 생성
    
    ## 인증 방법
    모든 보호된 엔드포인트는 Authorization 헤더에 Bearer 토큰이 필요합니다:
    ```
    Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
    ```
  version: 1.0.0

paths:
  /v1/auth/login:
    post:
      tags:
        - Authentication
      summary: 사용자 로그인
      description: |
        이메일과 비밀번호로 로그인하여 JWT 토큰을 발급받습니다.
        
        ## 로그인 프로세스
        1. 사용자 정보 검증
        2. 비밀번호 확인 (BCrypt)
        3. 계정 상태 확인
        4. JWT 토큰 생성 (Access + Refresh)
        5. 권한 정보 포함하여 응답
      operationId: login
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/LoginRequest'
            examples:
              super_admin:
                summary: 슈퍼관리자 로그인
                value:
                  email: "super@smartcon.co.kr"
                  password: "password123"
              hq_admin:
                summary: 본사 관리자 로그인
                value:
                  email: "hq@company.com"
                  password: "password123"
              site_manager:
                summary: 현장 관리자 로그인
                value:
                  email: "site@company.com"
                  password: "password123"
      responses:
        '200':
          description: 로그인 성공
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/LoginResponse'
              examples:
                success:
                  summary: 성공적인 로그인
                  value:
                    success: true
                    message: "로그인 성공"
                    data:
                      accessToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
                      refreshToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
                      user:
                        id: 1
                        email: "admin@company.com"
                        name: "관리자"
                        role: "ROLE_SUPER"
                        tenantId: "company-001"
                      permissions:
                        admin.read: true
                        admin.write: true
                        subscription.approve: true
        '400':
          description: 잘못된 요청
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                invalid_credentials:
                  summary: 잘못된 자격증명
                  value:
                    success: false
                    message: "이메일 또는 비밀번호가 올바르지 않습니다."
                    error: "INVALID_CREDENTIALS"
        '401':
          description: 인증 실패
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                account_locked:
                  summary: 계정 잠금
                  value:
                    success: false
                    message: "계정이 잠겨있습니다. 관리자에게 문의하세요."
                    error: "ACCOUNT_LOCKED"
                account_disabled:
                  summary: 계정 비활성화
                  value:
                    success: false
                    message: "비활성화된 계정입니다."
                    error: "ACCOUNT_DISABLED"

  /v1/auth/refresh:
    post:
      tags:
        - Authentication
      summary: 토큰 갱신
      description: |
        Refresh Token을 사용하여 새로운 Access Token을 발급받습니다.
        
        ## 토큰 갱신 프로세스
        1. Refresh Token 유효성 검증
        2. 토큰 타입 확인 (refresh)
        3. 사용자 정보 추출
        4. 새로운 Access Token 생성
        5. 기존 Refresh Token 재사용
      operationId: refreshToken
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/RefreshTokenRequest'
            examples:
              valid_refresh:
                summary: 유효한 Refresh Token
                value:
                  refreshToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
      responses:
        '200':
          description: 토큰 갱신 성공
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/RefreshTokenResponse'
              examples:
                success:
                  summary: 성공적인 토큰 갱신
                  value:
                    success: true
                    message: "토큰 갱신 성공"
                    data:
                      accessToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
                      refreshToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
        '400':
          description: 잘못된 요청
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                invalid_token_type:
                  summary: 잘못된 토큰 타입
                  value:
                    success: false
                    message: "Access Token으로는 갱신할 수 없습니다. Refresh Token을 사용하세요."
                    error: "INVALID_TOKEN_TYPE"
        '401':
          description: 토큰 갱신 실패
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                expired_token:
                  summary: 만료된 토큰
                  value:
                    success: false
                    message: "만료된 Refresh Token입니다."
                    error: "TOKEN_EXPIRED"
                invalid_token:
                  summary: 유효하지 않은 토큰
                  value:
                    success: false
                    message: "유효하지 않은 Refresh Token입니다."
                    error: "INVALID_TOKEN"

  /v1/auth/logout:
    post:
      tags:
        - Authentication
      summary: 로그아웃
      description: |
        현재 사용 중인 Access Token을 블랙리스트에 추가하여 로그아웃합니다.
        
        ## 로그아웃 프로세스
        1. Authorization 헤더에서 토큰 추출
        2. 토큰 유효성 검증
        3. 토큰을 블랙리스트에 추가
        4. 로그아웃 성공 응답
      operationId: logout
      security:
        - bearerAuth: []
      responses:
        '200':
          description: 로그아웃 성공
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/LogoutResponse'
              examples:
                success:
                  summary: 성공적인 로그아웃
                  value:
                    success: true
                    message: "로그아웃 성공"
        '401':
          description: 인증 실패
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                missing_token:
                  summary: 토큰 누락
                  value:
                    success: false
                    message: "Authorization 헤더가 필요합니다."
                    error: "MISSING_AUTHORIZATION_HEADER"
                invalid_token:
                  summary: 유효하지 않은 토큰
                  value:
                    success: false
                    message: "유효하지 않은 토큰입니다."
                    error: "INVALID_TOKEN"

  /v1/auth/validate:
    post:
      tags:
        - Token Management
      summary: 토큰 검증
      description: |
        JWT 토큰의 유효성을 검증하고 토큰 정보를 반환합니다.
        
        ## 검증 프로세스
        1. 토큰 형식 확인
        2. 서명 검증
        3. 만료 시간 확인
        4. 블랙리스트 확인
        5. 토큰 정보 추출 및 반환
      operationId: validateToken
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/TokenValidationRequest'
            examples:
              valid_token:
                summary: 유효한 토큰
                value:
                  token: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
      responses:
        '200':
          description: 토큰 검증 결과
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/TokenValidationResponse'
              examples:
                valid:
                  summary: 유효한 토큰
                  value:
                    success: true
                    message: "토큰 검증 성공"
                    data:
                      valid: true
                      userId: 1
                      tenantId: "company-001"
                      role: "ROLE_SUPER"
                      expiresAt: "2026-01-12T15:30:00Z"
                invalid:
                  summary: 유효하지 않은 토큰
                  value:
                    success: true
                    message: "토큰 검증 완료"
                    data:
                      valid: false
        '400':
          description: 잘못된 요청
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                malformed_token:
                  summary: 잘못된 토큰 형식
                  value:
                    success: false
                    message: "토큰 형식이 올바르지 않습니다."
                    error: "MALFORMED_TOKEN"

  /v1/auth/dev-token:
    post:
      tags:
        - Development Tools
      summary: 개발용 토큰 생성
      description: |
        개발 및 테스트 환경에서 사용할 수 있는 JWT 토큰을 생성합니다.
        
        ## 주의사항
        - 이 API는 개발 환경에서만 사용 가능합니다
        - 운영 환경에서는 비활성화됩니다
        
        ## 기본값
        - role: ROLE_SUPER (생략 시)
        - tenantId: dev-tenant (생략 시)
      operationId: generateDevToken
      requestBody:
        required: false
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/DevTokenRequest'
            examples:
              super_admin:
                summary: 슈퍼관리자 토큰
                value:
                  role: "ROLE_SUPER"
                  tenantId: "test-tenant"
              site_manager:
                summary: 현장 관리자 토큰
                value:
                  role: "ROLE_SITE"
                  tenantId: "site-001"
              default:
                summary: 기본값 사용
                value: {}
      responses:
        '200':
          description: 개발용 토큰 생성 성공
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/DevTokenResponse'
              examples:
                success:
                  summary: 성공적인 토큰 생성
                  value:
                    success: true
                    message: "개발용 토큰 생성 성공"
                    data:
                      accessToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
                      refreshToken: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
                      user:
                        id: 999
                        email: "dev@test.com"
                        name: "개발자"
                        role: "ROLE_SUPER"
                        tenantId: "test-tenant"
        '403':
          description: 개발 환경에서만 사용 가능
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/ErrorResponse'
              examples:
                production_env:
                  summary: 운영 환경에서 접근
                  value:
                    success: false
                    message: "개발용 토큰 생성은 개발 환경에서만 사용 가능합니다."
                    error: "DEV_ONLY_FEATURE"

components:
  securitySchemes:
    bearerAuth:
      type: http
      scheme: bearer
      bearerFormat: JWT
      description: |
        JWT 토큰을 사용한 인증입니다.
        
        Authorization 헤더에 다음 형식으로 토큰을 포함하세요:
        ```
        Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
        ```

  schemas:
    LoginRequest:
      type: object
      required:
        - email
        - password
      properties:
        email:
          type: string
          format: email
          description: 사용자 이메일 주소
          example: "admin@company.com"
        password:
          type: string
          format: password
          description: 사용자 비밀번호
          example: "password123"
          minLength: 8

    LoginResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: true
        message:
          type: string
          description: 응답 메시지
          example: "로그인 성공"
        data:
          type: object
          properties:
            accessToken:
              type: string
              description: JWT Access Token
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
            refreshToken:
              type: string
              description: JWT Refresh Token
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
            user:
              $ref: '#/components/schemas/User'
            permissions:
              type: object
              description: 사용자 권한 정보
              additionalProperties:
                type: boolean
              example:
                admin.read: true
                admin.write: true
                subscription.approve: true

    RefreshTokenRequest:
      type: object
      required:
        - refreshToken
      properties:
        refreshToken:
          type: string
          description: JWT Refresh Token
          example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

    RefreshTokenResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: true
        message:
          type: string
          description: 응답 메시지
          example: "토큰 갱신 성공"
        data:
          type: object
          properties:
            accessToken:
              type: string
              description: 새로운 JWT Access Token
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
            refreshToken:
              type: string
              description: JWT Refresh Token (재사용)
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

    LogoutResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: true
        message:
          type: string
          description: 응답 메시지
          example: "로그아웃 성공"

    TokenValidationRequest:
      type: object
      required:
        - token
      properties:
        token:
          type: string
          description: 검증할 JWT 토큰
          example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

    TokenValidationResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: true
        message:
          type: string
          description: 응답 메시지
          example: "토큰 검증 성공"
        data:
          type: object
          properties:
            valid:
              type: boolean
              description: 토큰 유효성
              example: true
            userId:
              type: integer
              description: 사용자 ID (유효한 토큰인 경우)
              example: 1
            tenantId:
              type: string
              description: 테넌트 ID (유효한 토큰인 경우)
              example: "company-001"
            role:
              type: string
              description: 사용자 역할 (유효한 토큰인 경우)
              example: "ROLE_SUPER"
            expiresAt:
              type: string
              format: date-time
              description: 토큰 만료 시간 (유효한 토큰인 경우)
              example: "2026-01-12T15:30:00Z"

    DevTokenRequest:
      type: object
      properties:
        role:
          type: string
          description: 사용자 역할 (기본값: ROLE_SUPER)
          enum:
            - ROLE_SUPER
            - ROLE_HQ
            - ROLE_SITE
            - ROLE_TEAM
            - ROLE_WORKER
          example: "ROLE_SUPER"
        tenantId:
          type: string
          description: 테넌트 ID (기본값: dev-tenant)
          example: "test-tenant"

    DevTokenResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: true
        message:
          type: string
          description: 응답 메시지
          example: "개발용 토큰 생성 성공"
        data:
          type: object
          properties:
            accessToken:
              type: string
              description: JWT Access Token
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
            refreshToken:
              type: string
              description: JWT Refresh Token
              example: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
            user:
              $ref: '#/components/schemas/User'

    User:
      type: object
      properties:
        id:
          type: integer
          description: 사용자 ID
          example: 1
        email:
          type: string
          format: email
          description: 사용자 이메일
          example: "admin@company.com"
        name:
          type: string
          description: 사용자 이름
          example: "관리자"
        role:
          type: string
          description: 사용자 역할
          enum:
            - ROLE_SUPER
            - ROLE_HQ
            - ROLE_SITE
            - ROLE_TEAM
            - ROLE_WORKER
          example: "ROLE_SUPER"
        tenantId:
          type: string
          description: 테넌트 ID
          example: "company-001"

    ErrorResponse:
      type: object
      properties:
        success:
          type: boolean
          description: 요청 성공 여부
          example: false
        message:
          type: string
          description: 오류 메시지
          example: "인증에 실패했습니다."
        error:
          type: string
          description: 오류 코드
          example: "AUTHENTICATION_FAILED"

security:
  - bearerAuth: []
```
