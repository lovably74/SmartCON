## 1. 문서 개요

본 문서는 SmartCON Lite SaaS 플랫폼의 전체 메뉴 구조를 역할별로 정리한 구성도입니다. 5단계 사용자 역할(슈퍼관리자, 본사관리자, 현장관리자, 팀장, 노무자)별 메뉴 경로와 기능을 명시합니다.

---

## 2. 공통 메뉴 (인증/인트로)

### 2.1 인트로 페이지
- **경로**: `/`
- **설명**: 서비스 소개 및 로그인 진입점
- **메뉴 구성**:
  - 비대면바우처 (배지)
  - 스마트콘 소개
  - 스마트콘 핵심기능
  - 서비스요금
  - 문의하기
  - 로그인 버튼

### 2.2 로그인
- **경로**: `/login`
- **설명**: 로그인 방식 선택
- **하위 경로**:
  - `/login/hq` - 본사 관리자 로그인 (사업자번호 + 비밀번호)
  - `/login/social` - 소셜 로그인 (Kakao, Naver OAuth2)

### 2.3 역할 선택
- **경로**: `/role-select`
- **설명**: 다중 역할 사용자의 역할/현장 선택

### 2.4 구독 신청
- **경로**: `/subscribe`
- **설명**: 신규 구독 신청 프로세스

## 3. 슈퍼 관리자 (ROLE_SUPER) 메뉴

**접근 플랫폼**: Web Only

### 3.1 대시보드
- **경로**: `/super/dashboard`
- **주요 위젯**:
  - 전체 MRR(월 반복 매출)
  - 가입 테넌트 수 및 증가율
  - 시스템 리소스 현황 (CPU, 메모리)
  - 결제 실패 알림
  - 고객사별 사용량 차트

### 3.2 테넌트 관리
- **경로**: `/super/tenants`
- **기능**:
  - 테넌트 목록 조회 (페이징, 검색, 정렬)
  - 테넌트 상세 정보 (`/super/tenants/{tenantId}`)
  - 테넌트 상태 관리 (ACTIVE, SUSPENDED, TERMINATED, TRIAL)

### 3.3 결제 및 정산 관리
- **경로**: `/super/billing`
- **하위 메뉴**:
  - `/super/billing/dashboard` - 결제 대시보드 (MRR, 신규/해지 고객, 결제 성공률)
  - `/super/billing/failed-payments` - 결제 실패 관리
  - `/super/billing/tax-invoices` - 세금계산서 발행 관리

### 3.4 시스템 설정
- **경로**: `/super/settings`
- **기능**: 시스템 전체 설정 관리

## 5. 현장 관리자 (ROLE_SITE) 메뉴

**접근 플랫폼**: Web + Mobile

### 5.1 대시보드
- **경로**: `/site/dashboard`
- **주요 위젯**:
  - 금일 출역 현황 (출근/퇴근/현재 현장)
  - 작업 팀 현황 (배정/진행/완료)
  - 미처리 업무 (승인 대기, 일보 미제출)
  - 일별 출역 인원 차트
  - 공종별 투입 인원
  - 계약 체결 현황

### 5.2 출역 관리
- **경로**: `/site/attendance`
- **하위 메뉴**:
  - `/site/attendance/today` - 실시간 출역 현황
  - `/site/attendance/logs` - 출역 기록 조회
  - `/site/attendance/finalize` - 출역 마감/승인

### 5.3 작업 관리
- **경로**: `/site/work-assignments`
- **기능**:
  - 작업 계획 및 배정
  - 작업 요청 생성 및 발송
  - 작업 진행 상황 모니터링

### 5.4 공사일보
- **경로**: `/site/daily-reports`
- **기능**:
  - 일보 취합 및 작성
  - 날씨 정보 자동 연동 (기상청 API)
  - 팀별 제출 내용 확인 및 승인
  - 일보 이력 조회 (`/site/daily-reports/history`)

### 5.5 계약 관리
- **경로**: `/site/contracts`
- **기능**: 현장 계약서 현황 및 관리

### 5.6 팀 관리
- **경로**: `/site/teams`
- **기능**:
  - 팀 목록 조회
  - 팀 등록 및 팀장 초대
  - 팀 승인/반려 처리

### 5.7 급여 관리
- **경로**: `/site/salary`
- **기능**: 현장 노무자 급여 관리

### 5.8 현장 설정
- **경로**: `/site/settings`
- **기능**: 현장 전용 설정 (공종/장비, 안면인식기 관리)

## 9. 네비게이션 구조

### 9.1 PC Web 네비게이션 (사이드바)

**레이아웃**:
- 좌측 접기/펼치기 가능한 사이드바 (250px 확장, 64px 축소)
- 상단 헤더 (페이지 타이틀, 현장 선택, 알림, 사용자 메뉴)
- 대시보드는 메뉴에서 제외하고, 로그인 후 최초 진입 화면으로 고정
- 좌측 상단 SmartCON 로고 클릭 시 현재 역할의 대시보드로 이동

**사이드바 구조 예시 (본사 관리자)**:
```
[SmartCON 로고]
├── 📊 현장 관리
├── 👥 노무자 관리
├── 📄 계약 관리
├── 💰 정산 관리
├── ⚙️ 표준 관리
├── 📋 구독 관리
└── ⚙️ 설정
```

### 9.2 Mobile Web 네비게이션 (하단 탭바)

**레이아웃**:
- 하단 Bottom Navigation (핵심 4-5개 탭)
- 상단 Sticky Header
- 선택/상세는 Bottom Sheet 패턴

**하단 탭 구조 예시 (노무자)**:
```
[홈] [출역] [계약] [내정보]
  │     │      │       │
대시보드  출역   전자계약  프로필
```

## 11. 참고 사항

### 11.1 메뉴 표시 규칙
- 대시보드는 메뉴에 표시하지 않음 (로그인 후 최초 진입 화면)
- 역할별 권한에 따라 메뉴 항목이 동적으로 표시/숨김 처리
- 다중 역할 사용자는 역할 선택 후 해당 역할의 메뉴 표시

### 11.2 경로 규칙
- 역할별 경로는 `/역할코드/기능` 형식을 기본으로 함
  - 예: `/hq/sites`, `/site/dashboard`, `/worker/attendance`
- 상세 페이지는 `/기능/{id}` 형식을 사용
  - 예: `/super/tenants/{tenantId}`, `/worker/contracts/{contractId}/sign`
- 하위 기능은 `/기능/하위기능` 형식을 사용
  - 예: `/site/attendance/today`, `/hq/standards/work-types`

### 11.3 반응형 처리
- PC: 좌측 사이드바 + 메인 컨텐츠 영역
- Tablet: 축소형 사이드바 또는 상단 메뉴
- Mobile: 하단 탭바 + 드로어 메뉴
