## 📋 새로운 요구사항 체크리스트

### 통합 로그인 시스템
- [ ] **개인사용자 로그인**: 소셜(카카오톡, 네이버) 로그인 구현
- [ ] **관리자 로그인**: 사업자번호 + 비밀번호 + 2차 이메일 인증
- [ ] **CI값 관리**: 전화번호 인증을 통한 고유 키값 생성 및 관리
- [ ] **다중 권한 선택**: 2개 이상 권한 보유 시 선택 기능
- [ ] **현장 선택**: 현장관리자/노무팀장의 다중 현장 선택

### 5단계 역할 기반 시스템
- [ ] **본사관리자**: 전체 현장 및 노무자 관리 기능
- [ ] **현장관리자**: 현장별 출역 및 계약 관리 기능
- [ ] **노무팀장**: 팀별 출역 및 계약 현황 관리 기능
- [ ] **일반노무자**: 개인 출역 및 계약 현황 조회 기능
- [ ] **슈퍼관리자**: 시스템 전체 관리 (기존 유지)

### 모바일 우선 설계
- [ ] **PC웹**: 반응형 웹 디자인
- [ ] **모바일웹**: 모바일 최적화 웹
- [ ] **모바일앱**: Android/iOS 네이티브 앱 (Capacitor)
- [ ] **크로스 플랫폼**: 동일한 기능 및 사용자 경험

### 안면인식 등록 시스템
- [ ] **기본 개인정보**: 개인정보에 안면정보 등록
