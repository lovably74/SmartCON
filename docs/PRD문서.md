## 1. 프로젝트 개요 (Project Overview)

본 프로젝트는 건설 현장의 인력 및 노무 관리를 위한 **'스마트콘 라이트(SmartCON Lite)'** 역할 기반 시스템을 구축하는 것을 목표로 합니다.  
변경된 요구사항에 따라 5단계 사용자 역할(본사관리자, 현장관리자, 노무팀장, 일반노무자, 슈퍼관리자)별로 최적화된 기능을 제공하며, 모바일 우선 설계와 안면인식 기반 출역 관리를 핵심으로 합니다.

### 1.1 핵심 목표
- **Role-Based System**: 5단계 사용자 역할별 최적화된 기능 제공
- **Mobile First**: PC웹, 모바일웹, 모바일앱(Android/iOS) 지원
- **Social Authentication**: 카카오톡, 네이버 소셜 로그인 및 CI값 기반 사용자 관리
- **Face Recognition**: 안면인식 기반 출역 자동화
- **Multi-Platform**: 모든 화면 UI는 PC웹, 모바일웹, 모바일앱 구성

### 1.2 핵심 가치 제안
**"현장의 신뢰, 기술로 완성하다" (Building Trust Through Technology)**

- **Transparency**: 객관적인 안면인식 기반 출역 관리
- **Convenience**: 모바일 우선의 직관적 사용자 경험  
- **Flexibility**: 다양한 건설 현장 환경에 적응 가능한 시스템

### 1.3 주요 기능 변경사항
- **통합 로그인 시스템**: 개인사용자(소셜 로그인) / 관리자(사업자번호+비밀번호) 구분
- **CI값 기반 사용자 관리**: 전화번호 인증을 통한 고유 키값 생성 및 계정 연동
- **역할별 대시보드**: 본사관리자, 현장관리자, 노무팀장, 일반노무자별 맞춤 대시보드
- **현장 선택 시스템**: 다중 현장 소속 사용자를 위한 현장 선택 인터페이스
- **안면인식 등록**: 기본 개인정보 활용 및 현장별 수정 기능

## 2. 기술 스택 (Tech Stack)

### 2.1 Backend
- **Language**: Java 17 (LTS)
- **Framework**: Spring Boot 3.3.x
- **Database**: MariaDB 10.11 (JPA/Hibernate) - Multi-tenant Schema
- **Security**: Spring Security 6.x + JWT + OAuth2 Client (Kakao, Naver)
- **Infrastructure**: Docker, AWS (S3 for files)

### 2.2 Frontend (Web & Mobile WebApp)
- **Framework**: React 18 + TypeScript + Vite
- **State Mgmt**: TanStack Query + Zustand
- **UI System**: **Shadcn/UI** + **Tailwind CSS** (Custom Design System applied)
- **Mobile Bridge**: Capacitor (Camera, Geolocation, Push, Deep Link)

### 2.3 Mobile App
- **Android**: Capacitor 기반 하이브리드 앱
- **iOS**: Capacitor 기반 하이브리드 앱
- **Native Features**: 카메라, GPS, 푸시알림, 안면인식

### 2.4 External Interfaces
- **Face Recognition**: FaceNet (Face Embedding & Matching Server)
- **Social Login**: Kakao OAuth2, Naver OAuth2
- **SMS Gateway**: 전화번호 인증 및 알림
- **CI Service**: 전화번호 인증을 통한 연계정보 생성

## 3. 사용자 역할 및 권한 (User Roles)

### 3.1. 본사관리자 (HQ Administrator)
- **인증 방식**: 사업자번호 + 비밀번호 + 2차 인증(이메일)
- **주요 기능**:
  - **대시보드**: 진행중 현장 수, 등록 노무자 수, 미서명 계약 수, 월별 출역 현황, 공종별 인원 분포
  - **프로젝트 현황**: 신규 프로젝트 등록, 프로젝트 목록 관리, 현장관리자 초대
  - **출역현황**: 전체 현장 출역현황 조회
  - **근로계약현황**: 프로젝트별 근로계약서 목록 및 관리
  - **노무자현황**: 전체 노무자 목록 및 통계
  - **관리자관리**: 본사관리자 목록 및 초대
  - **구독관리**: 회사정보, 계약담당자, 청구서 조회, 결재 이력

### 3.2. 현장관리자 (Site Manager)
- **인증 방식**: 소셜 로그인 (Kakao, Naver) + 현장 선택
- **주요 기능**:
  - **대시보드**: 금일 신규 출역자 수, 금일 총 출역자 수, 미서명 계약 수, 일별 출역 현황, 공종별 인원 분포
  - **프로젝트 개요**: 현장 정보 조회
  - **출역현황**: 현장 출역현황 조회 및 수정
  - **근로계약현황**: 현장 근로계약서 관리 및 수정요청 처리
  - **노무자현황**: 현장 노무자 목록 및 기본단가 관리
  - **신규출역자 확인**: 신규 출역 요청자 승인 관리

### 3.3. 노무팀장 (Team Leader)
- **인증 방식**: 소셜 로그인 (Kakao, Naver) + 현장 선택
- **주요 기능**:
  - **대시보드**: 팀원수, 오늘 출역 수, 최근 1주 출역 현황, 팀원현황, 공종별 인원
  - **프로젝트 개요**: 프로젝트 정보 조회
  - **출역조회**: 팀원 출역현황 조회
  - **근로계약현황**: 팀원 근로계약서 관리 및 서명 요청
  - **노무자현황**: 팀원 목록 및 관리

### 3.4. 일반노무자 (Worker)
- **인증 방식**: 소셜 로그인 (Kakao, Naver) + 현장 선택
- **주요 기능**:
  - **대시보드**: 팀원수, 오늘 출역 수, 최근 1주 출역 현황, 팀원현황, 공종별 인원
  - **프로젝트 개요**: 프로젝트 정보 조회
  - **출역조회**: 개인 출역현황 조회
  - **근로계약현황**: 개인 근로계약서 관리 및 변경 요청
  - **안면인식 등록**: 출역용 안면정보 등록 및 수정

### 3.5. 슈퍼관리자 (Super Admin)
- **권한**: 시스템 전체 관리 (구독신청 페이지 제외)
- **주요 기능**: 시스템 운영 및 관리 (기존 기능 유지)

## 4. 핵심 기능 명세

### 4.1. 공통 로그인 시스템

#### 4.1.1 모바일 로그인 인터페이스
- **사용자 구분**: "개인사용자", "관리자" 탭 선택
- **개인사용자 로그인**:
  - 소셜 로그인 옵션: 카카오톡, 네이버
  - 최초 로그인시 전화번호 인증 수행
  - CI값 생성 및 계정 연동 처리
- **관리자 로그인**:
  - 사업자번호 + 비밀번호 입력
  - 2차 인증: 구독신청시 등록한 이메일로 인증

#### 4.1.2 로그인 후 처리
- **권한 검토**: 사용자 소유 권한 확인
- **다중 역할 처리**: 2개 이상 권한 소유시 역할 선택 인터페이스
- **현장 선택**: 현장관리자/노무팀장의 다중 현장 소속시 현장 선택
- **현장 목록 정렬**: 최근 로그인 현장 → 최근 투입 현장 → 준공예정일 많이 남은 현장 순
- **필터링**: "전체현장", "진행중현장", "완료현장" 선택
- **검색**: 현장명 검색 기능

### 4.2. 내정보 관리
- **개인정보**: 이름, 휴대전화번호, 이메일 주소, 급여 계좌정보, 사진, 주민번호, 비상연락처, 자택주소
- **소셜계정**: 연결된 소셜계정 정보 조회 및 추가

### 4.3. 화면 UI 지원
- **PC웹**: 데스크톱 브라우저 지원
- **모바일웹**: 모바일 브라우저 지원
- **모바일앱**: Android 및 iOS 네이티브 앱 지원

### 4.4. 본사관리자 기능

#### 4.4.1 대시보드
- **KPI 지표**: 진행중 현장 카운트, 등록(활성) 노무자 카운트, 전체 현장 미서명 계약 카운트
- **차트**: 월별 출역 현황 barchart, 공종별 인원 분포 barchart

#### 4.4.2 프로젝트 현황
- **신규 등록**: 현장명, 공사기간, 현장소장, 안면인식기, 현장관리자 선택/초대
- **목록 관리**: 현장명, 공사기간, 현장소장, 상태, 출역인원, 등록일, 안면인식기 등록 수
- **검색/필터**: 현장명 검색, 상태별 필터링

#### 4.4.3 출역현황
- **전체 현장**: 프로젝트명, 출역노무자명, 출근시각, 퇴근시각, 출역공수, 단가, 변경사항 및 사유

#### 4.4.4 근로계약현황
- **계약 목록**: 프로젝트명, 출역일, 노무자명, 연락처, 서명 여부, 계약서 보기
- **필터링**: 프로젝트별, 월별, 일별 조회

#### 4.4.5 노무자현황
- **노무자 목록**: 노무자명, 연락처, 근무현장 수, 총 출역일, 근로계약서 카운트, 최초/마지막 출역일

#### 4.4.6 관리자관리
- **관리자 목록**: 이름, 전화번호, 이메일, 직책, 상태, 입사일, 퇴사일
- **초대 기능**: 이름, 휴대전화, 이메일 등록하여 초대

#### 4.4.7 구독관리
- **회사정보 관리**
- **계약담당자 관리**
- **청구서 및 계산서 조회**
- **결재 이력 조회**

### 4.5. 현장관리자 기능

#### 4.5.1 대시보드
- **KPI 지표**: 금일 신규 출역자 카운트, 금일 총 출역자 카운트, 미서명 계약 카운트

#### 4.6.3 근로계약현황

### 4.7. 일반노무자 기능

- **검색**: 기간별, 이름, 공종별, 프로젝트별 검색

#### 4.7.3 근로계약현황
- **계약 관리**: 출역일, 프로젝트명, 단가, 공종, 서명 여부
- **변경 요청**: 계약내용 변경 요청 기능(메모 형식)

## 5. 인증 및 보안 요구사항

### 5.1 인증 시스템
- **소셜 로그인**: Kakao, Naver OAuth2 연동
- **사업자 로그인**: 사업자번호 + 비밀번호 + 2차 인증
- **CI값 관리**: 전화번호 인증을 통한 고유 키값 생성
- **계정 연동**: CI값 기반 소셜계정 추가 연동

### 5.2 보안 요구사항
- **계정 보안**: 5회 실패시 30분 계정 잠금
- **로그 관리**: 모든 인증 시도 로그 기록
- **데이터 암호화**: 개인정보 AES-256 암호화
- **전송 보안**: HTTPS 강제, TLS 1.3 이상

### 5.3 권한 관리
- **역할 기반 접근 제어**: 5단계 사용자 역할별 권한 관리
- **현장별 권한**: 현장 단위 데이터 접근 제어
- **다중 역할**: 한 사용자의 여러 역할 및 현장 관리
